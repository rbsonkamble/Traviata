# Traviata Journeyscribe – Demo

Static HTML homepage demo for Traviata Journeyscribe.

## Publish with GitHub Pages
1. Upload `index.html` and `.nojekyll` to the repository root.
2. In **Settings → Pages**, select **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`.
4. Save, then check **Actions** for the Pages deployment status.

The logo is embedded in `index.html`. Some photography and fonts are loaded from external providers, so those elements require an internet connection.
